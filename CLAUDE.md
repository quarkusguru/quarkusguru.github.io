# Blog writing style

All tutorials and blog posts must follow [TUTORIAL_STYLE_GUIDE.md](./TUTORIAL_STYLE_GUIDE.md). Read it before writing or editing any post in `content/posts/`.

Key rules from that guide (non-exhaustive, see the file for the full standard):
- Do not use the em dash character (—). Use a semicolon, parentheses, or two separate sentences instead.
- Do not use contractions; write the full form ("cannot", "do not", "it is", "let us", etc.).
- Do not use a colon to join clauses in prose; colons may still introduce a list or a code block.
- Follow the standard section structure (Overview, Prerequisites, main content, Testing, Best Practices, Conclusion) and code style guidelines defined in the guide.
